# Syllabus Page References per Section

## Summary

Each Learn section shows the official syllabus section and page number ("Syllabus 5.3.4, p. 34") with a link to the official PDF. Learners can jump to the source text to check wording before the exam.

## Why it fits

Section ids already match syllabus numbering; only page numbers and PDF URLs are missing. It supports learners who want to verify paraphrased content.

## Scope

- `syllabusUrl` per track and `page` per section in data
- Small reference line under each Learn section heading
- Script to extract page numbers from the PDFs in `trainings/`

## Risks & unknowns

- Official PDF URLs change between releases
