# Hands-On Exercises (Not Exam Questions)

## Summary

Practical tasks attached to technique sections: design boundary values for a real form, write Gherkin for a user story, run a heuristic evaluation of a sample screen, plan a load profile. Each has a worked solution. People build skills, not just recognition.

## Why it fits

Learn already has `example` blocks; exercises extend them with a task and a hidden solution. They're clearly labelled practice, so they don't conflict with the no-invented-exam-questions rule.

## Scope

- New `exercise` learn block: task, hints, reveal solution
- Start with K3/K4 technique sections (BVA, decision tables, Gherkin, heuristics, load profiles)
- Exercise index per track

## Risks & unknowns

- Writing good exercises and solutions takes real effort; quality must be reviewed
