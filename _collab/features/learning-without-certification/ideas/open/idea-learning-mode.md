# Learning Mode Without Exam Framing

## Summary

A site-wide switch between Exam mode (today) and Learning mode, which hides K-levels, LO codes, exam insights and pass marks, and puts examples and plain explanations first. Casual learners aren't put off by exam jargon.

## Why it fits

Exam framing is everywhere (KChips, LO ids, quiz-first CTAs). The data separates these fields cleanly, so a mode can hide them.

## Scope

- Mode toggle in the Shell next to the theme toggle, remembered per browser
- Learn/Summary pages hide exam-only fields in Learning mode
- Track page reworded ("Practice questions" instead of "mock exam")

## Risks & unknowns

- Two modes double the states to design and test
