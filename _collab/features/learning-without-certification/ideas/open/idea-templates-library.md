# Templates and Checklists Library

## Summary

Ready-to-use templates drawn from the syllabi: test plan outline, exploratory test charter, bug report, usability test script and report, risk matrix, Gherkin feature file, performance test plan, security test checklist. People use them at work tomorrow.

## Why it fits

The syllabi describe these artefacts in detail (e.g. CT-UT 5.3.1 test plan contents, CT-AcT charters); the site already paraphrases them in Learn.

## Scope

- Templates page with copy-to-clipboard Markdown
- Each template links back to the section that explains it
- Filter by track and activity

## Risks & unknowns

- Downloads from static hosting are fine; keep templates paraphrased, not copied
