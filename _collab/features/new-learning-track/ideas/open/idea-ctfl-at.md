# Foundation Level Agile Tester (CTFL-AT)

## Summary

Add ISTQB's Foundation Level Agile Tester extension: agile principles and the tester's role in agile teams, agile testing methods and quadrants, estimation, and agile test tools. It's a short, entry-level add-on to CTFL.

## Why it fits

It's a low-effort follow-on for CTFL learners (the hub's “START HERE” track) and a gentler alternative to CTAL-ATT for people not ready for Advanced. Follows the established track recipe from the done tasks (CTFL v4, CT-QDO, CT-MAT, CT-SS): `src/data/<id>/` (chapters + learn content + official sample-exam quiz checked against the answer key + glossary), five step pages (Learn / Summaries / Exam Insights / Glossary / Quiz with a timed mock), a `makeProgress` storage key, and one `tracks.js` entry, which makes it appear on the hub, the track page and the breadcrumbs automatically.

## Scope

- All chapters, learn content, sample exam quiz, glossary
- New `tracks.js` entry, progress key, five step pages, hub card
