# Acceptance Testing (CT-AcT)

## Summary

Add the Acceptance Testing specialist syllabus: business-facing acceptance criteria, user/operational/contract acceptance testing, ATDD and BDD in practice, and collaboration with business analysts and product owners.

## Why it fits

It builds directly on CTFL 2.1.3 (test-first approaches: TDD/ATDD/BDD) and 2.2.1 (acceptance test level), which the CTFL Learn content already covers, and it suits BA/PO-adjacent learners. Follows the established track recipe from the done tasks (CTFL v4, CT-QDO, CT-MAT, CT-SS): `src/data/<id>/` (chapters + learn content + official sample-exam quiz checked against the answer key + glossary), five step pages (Learn / Summaries / Exam Insights / Glossary / Quiz with a timed mock), a `makeProgress` storage key, and one `tracks.js` entry, which makes it appear on the hub, the track page and the breadcrumbs automatically.

## Scope

- All chapters, learn content, sample exam quiz, glossary
- New `tracks.js` entry, progress key, five step pages, hub card
