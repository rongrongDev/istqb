# Advanced Level Technical Test Analyst (CTAL-TTA)

## Summary

Add the Technical Test Analyst syllabus: white-box techniques (statement through MC/DC and multiple condition coverage), static and dynamic analysis, technical quality characteristics (security, reliability, performance efficiency, maintainability, portability), reviews and tools.

## Why it fits

It completes the Advanced Level core set alongside TA and TM, for developer-leaning testers. The CTFL track's white-box Learn section (4.3) is its starting point. Follows the established track recipe from the done tasks (CTFL v4, CT-QDO, CT-MAT, CT-SS): `src/data/<id>/` (chapters + learn content + official sample-exam quiz checked against the answer key + glossary), five step pages (Learn / Summaries / Exam Insights / Glossary / Quiz with a timed mock), a `makeProgress` storage key, and one `tracks.js` entry, which makes it appear on the hub, the track page and the breadcrumbs automatically.

## Scope

- All chapters with learn content
- Sample exam quiz (many calculation-style coverage questions)
- Glossary
- New `tracks.js` entry, progress key, five step pages, hub card
