# Model-Based Tester (CT-MBT)

## Summary

Add ISTQB's Model-Based Testing specialist syllabus: building test models (state machines, activity diagrams, decision tables), selecting tests from them with coverage criteria, and introducing MBT into a project's toolchain.

## Why it fits

It extends CTFL's state-transition and decision-table techniques (CTFL ch. 4), which already have Learn sections on the site, into a full modelling discipline. Follows the established track recipe from the done tasks (CTFL v4, CT-QDO, CT-MAT, CT-SS): `src/data/<id>/` (chapters + learn content + official sample-exam quiz checked against the answer key + glossary), five step pages (Learn / Summaries / Exam Insights / Glossary / Quiz with a timed mock), a `makeProgress` storage key, and one `tracks.js` entry, which makes it appear on the hub, the track page and the breadcrumbs automatically.

## Scope

- All chapters, learn content, sample exam quiz, glossary
- New `tracks.js` entry, progress key, five step pages, hub card
