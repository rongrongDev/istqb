# Game Testing (CT-GaMe)

## Summary

Add ISTQB's Game Testing specialist syllabus: testing game mechanics, graphics, sound, level design, controllers, multiplayer/network and localisation, and playtesting and other game-specific test types.

## Why it fits

A distinct, popular niche that broadens the hub's audience beyond enterprise QA. It sits naturally next to CT-MAT, since mobile games overlap with mobile app testing. Follows the established track recipe from the done tasks (CTFL v4, CT-QDO, CT-MAT, CT-SS): `src/data/<id>/` (chapters + learn content + official sample-exam quiz checked against the answer key + glossary), five step pages (Learn / Summaries / Exam Insights / Glossary / Quiz with a timed mock), a `makeProgress` storage key, and one `tracks.js` entry, which makes it appear on the hub, the track page and the breadcrumbs automatically.

## Scope

- All chapters, learn content, sample exam quiz, glossary
- New `tracks.js` entry, progress key, five step pages, hub card
