# Advanced Level Test Analyst (CTAL-TA v4.0)

## Summary

Add the Advanced Test Analyst syllabus, the most common next step after CTFL. v4.0 was rewritten from scratch; English v3.1 exams ended 16 May 2026 (non-English versions end 16 Nov 2026), so v4.0 is the version learners need now.

## Why it fits

CTFL is the hub's “START HERE” track, and Test Analyst is the most common Advanced-level next step from it. Several CTFL Learn sections (test techniques, risk-based testing) set up exactly what TA deepens. Follows the established track recipe from the done tasks (CTFL v4, CT-QDO, CT-MAT, CT-SS): `src/data/<id>/` (chapters + learn content + official sample-exam quiz checked against the answer key + glossary), five step pages (Learn / Summaries / Exam Insights / Glossary / Quiz with a timed mock), a `makeProgress` storage key, and one `tracks.js` entry, which makes it appear on the hub, the track page and the breadcrumbs automatically.

## Scope

- All v4.0 chapters with learn content and K-levels (Advanced has many K3/K4 objectives)
- Sample exam(s) as quiz, with the scenario-based question format Advanced exams use
- Glossary; links back to the matching CTFL sections for prerequisites
- New `tracks.js` entry, progress key, five step pages, hub card

## Risks & unknowns

- Advanced exams are longer (typically 120 min, scenario-heavy); the quiz/mock timer and layout may need a variant for long shared scenarios
- Larger syllabus than any current track, so a big authoring effort
