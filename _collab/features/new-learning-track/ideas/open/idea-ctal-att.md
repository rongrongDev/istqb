# Advanced Agile Technical Tester (CTAL-ATT)

## Summary

Add ISTQB's Advanced Agile Technical Tester syllabus: requirements engineering in agile, test-first practices (TDD/BDD/ATDD) at a technical level, test automation and continuous practices, refactoring and code-level quality.

## Why it fits

It complements the approved CTAL-TAE and CT-TAS automation tracks from the agile-team angle, and builds on the CTFL Learn content for test-first approaches. Follows the established track recipe from the done tasks (CTFL v4, CT-QDO, CT-MAT, CT-SS): `src/data/<id>/` (chapters + learn content + official sample-exam quiz checked against the answer key + glossary), five step pages (Learn / Summaries / Exam Insights / Glossary / Quiz with a timed mock), a `makeProgress` storage key, and one `tracks.js` entry, which makes it appear on the hub, the track page and the breadcrumbs automatically.

## Scope

- All chapters, learn content, sample exam quiz, glossary
- New `tracks.js` entry, progress key, five step pages, hub card
