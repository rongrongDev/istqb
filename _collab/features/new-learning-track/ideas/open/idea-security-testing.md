# Security Testing (CTAL-SEC / CT-SEC)

## Summary

Add ISTQB's security testing syllabus: security risks and threat modelling, security test techniques and tools, aligning testing with security policies, and evaluating results.

## Why it fits

Security appears briefly as a quality characteristic in CTFL and CT-MAT (mobile security). A dedicated track fills an obvious gap in the hub's specialisms. Follows the established track recipe from the done tasks (CTFL v4, CT-QDO, CT-MAT, CT-SS): `src/data/<id>/` (chapters + learn content + official sample-exam quiz checked against the answer key + glossary), five step pages (Learn / Summaries / Exam Insights / Glossary / Quiz with a timed mock), a `makeProgress` storage key, and one `tracks.js` entry, which makes it appear on the hub, the track page and the breadcrumbs automatically.

## Scope

- All chapters, learn content, sample exam quiz, glossary
- New `tracks.js` entry, progress key, five step pages, hub card

## Risks & unknowns

- ISTQB's naming and level for security have shifted over time; confirm the current certificate (code, level, version) before starting
