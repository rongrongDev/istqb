# Automotive Software Tester (CT-AuT)

## Summary

Add ISTQB's Automotive Software Tester specialist syllabus: testing in automotive projects under standards such as ASPICE, ISO 26262 functional safety and AUTOSAR, plus virtual test environments (MiL/SiL/HiL) and the techniques those standards require.

## Why it fits

It's the hub's first safety-critical domain track. It builds on CTFL's test levels and techniques, and its standards-driven content suits the existing Learn table and note blocks. Follows the established track recipe from the done tasks (CTFL v4, CT-QDO, CT-MAT, CT-SS): `src/data/<id>/` (chapters + learn content + official sample-exam quiz checked against the answer key + glossary), five step pages (Learn / Summaries / Exam Insights / Glossary / Quiz with a timed mock), a `makeProgress` storage key, and one `tracks.js` entry, which makes it appear on the hub, the track page and the breadcrumbs automatically.

## Scope

- All chapters, learn content, sample exam quiz, glossary of automotive and standards terms
- New `tracks.js` entry, progress key, five step pages, hub card

## Risks & unknowns

- Current version/code to confirm on istqb.org before authoring
- Heavy on standards vocabulary; paraphrase without reproducing the standards' own text
