# Test Automation Strategy (CT-TAS)

## Summary

Add the Specialist syllabus on planning and governing test automation at the organisation level: objectives and business case, automation strategy, test automation architecture choices, scaling, and measuring automation.

## Why it fits

A shorter, strategy-level alternative to CTAL-TAE that's popular with test leads. It sits well next to CT-QDO, which already covers the DevOps context automation lives in. Follows the established track recipe from the done tasks (CTFL v4, CT-QDO, CT-MAT, CT-SS): `src/data/<id>/` (chapters + learn content + official sample-exam quiz checked against the answer key + glossary), five step pages (Learn / Summaries / Exam Insights / Glossary / Quiz with a timed mock), a `makeProgress` storage key, and one `tracks.js` entry, which makes it appear on the hub, the track page and the breadcrumbs automatically.
