# Testing Anti-Patterns and Their Fixes

## Summary

A catalogue of common testing anti-patterns — ice-cream-cone test suite, flaky tests quarantined forever, 100% coverage as a target, QA as the release gatekeeper, testing only the happy path, bug-count metrics, automating an unstable UI first — each as symptom → why it happens → harm → fix, with links to the sections that explain the better practice.

## Why it fits

Learners recognise their own team in these, which makes the syllabus advice concrete. Different from trade-offs (a choice between valid options) and case studies (one incident).
