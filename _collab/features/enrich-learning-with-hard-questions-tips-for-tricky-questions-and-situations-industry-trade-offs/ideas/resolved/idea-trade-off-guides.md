# Trade-Off Decision Guides

## Summary

Short guides to the decisions teams argue about: mocks vs real dependencies, end-to-end vs contract tests, test pyramid vs testing trophy, staging vs testing in production, coded vs record-and-replay automation, synthetic vs masked production data, scripted vs exploratory testing, shift-left vs shift-right. Each gives the options, when each wins, the costs, and a decision table.

## Why it fits

The syllabi state principles but rarely compare options head-on; engineers who aren't sitting an exam want exactly this. Guides link to the sections that teach each side and to the Toolbox.

## Scope

- `src/data/learning/tradeoffs.js`: question, options with pros/cons, "choose when" rules, decision table, links
- Trade-offs page and a guide view
- Start with 8 guides
