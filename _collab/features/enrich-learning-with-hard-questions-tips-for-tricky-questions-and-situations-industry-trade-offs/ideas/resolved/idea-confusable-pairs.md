# Confusable Pairs Library

## Summary

A cross-track collection of terms that are easy to mix up — verification vs validation, confirmation vs regression testing, load vs stress, error vs defect vs failure, formative vs summative, authentication vs authorisation, RTO vs RPO — each with a one-line rule to tell them apart, a contrasting example and a quick "which is it?" drill.

## Why it fits

The Insights quick references already list "definition swaps" per track, but only as text inside one track. A shared library connects swaps that recur across syllabi and makes them drillable.

## Scope

- `src/data/learning/pairs.js`: pair, rule, example per side, tracks/sections
- Pairs page with a filter by track and a quick drill (show a scenario, pick which term)
- "Easily confused with…" note on the related glossary entries
