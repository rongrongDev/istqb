# Challenge Questions (Hard Mode)

## Summary

A separate bank of harder, original questions per track — multi-step scenarios, two-concept combinations, calculation questions with realistic noise — clearly labelled as written for this site, not official. Learners who pass the sample exams comfortably get something that still stretches them.

## Why it fits

Every track has only 40–80 official questions, and repeat takers memorise them. The official quizzes stay untouched; challenge questions reuse the QuizPage practice flow and the question shape (lo, level, chapter, explanation), with a "Challenge" pool.

## Scope

- `src/data/<track>/challenge.js` with original questions tied to LOs
- "Challenge" practice pool in QuizPage, never part of exam simulation or best-score records
- Each question explains every option, like the official ones
- Start with the K3/K4 objectives of a few tracks

## Risks & unknowns

- Earlier tasks set a rule against inventing unofficial exam questions; this would deliberately relax it for a labelled practice pool
- Quality: hard questions that are ambiguous do more harm than good — needs review
