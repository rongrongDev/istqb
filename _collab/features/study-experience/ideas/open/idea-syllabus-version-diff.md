# CT-AI v1 → v2 “What Changed” Guide

## Summary

A page that maps CT-AI v1.0 chapters/sections to v2.0 ones and highlights what's new, removed or reworded, so someone who studied v1 (or whose provider still teaches v1) can upgrade efficiently instead of restarting.

## Why it fits

The site holds both syllabi in full (`src/data/ctaiv1/`, 11 chapters; `src/data/ctaiv2/`, 7 chapters), and `TrackPage` already groups v1 under the CT-AI track with a note to check which version your exam uses. Nothing explains how the two relate.

## Scope

- Hand-curated mapping v1 section ↔ v2 section(s) with change type (new / moved / removed / reworded)
- Diff page grouped by v2 chapter, linking to both versions' Learn sections
- Glossary diff: terms added/removed between versions (computable from the two glossary files)
- Reusable shape for future syllabus revisions (e.g. a CTFL v4 → v5)

## Risks & unknowns

- Mapping accuracy needs both syllabi side by side; done once, it's static
