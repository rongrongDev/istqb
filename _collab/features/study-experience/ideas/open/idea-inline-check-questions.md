# Inline “Check Your Understanding” Questions

## Summary

After each Learn section, show 1–2 official sample questions mapped to that section's learning objective, answered in place with the explanation. You test recall straight after reading, before moving on.

## Why it fits

Quiz questions already carry `lo` (e.g. `FL-2.1.2`), and each learn section has an `objective` field with the same id format, so the mapping exists in the data. The Quiz page is a separate step at the end of the path, so today there's no retrieval practice while learning.

## Scope

- Collapsible “Check yourself (2)” block at the end of a section whose `objective` has quiz questions
- Reuse the quiz page's option/explanation rendering
- Option: a correct answer offers to mark the section studied

## Risks & unknowns

- Using official sample questions here “spends” them, so they're less fresh for the timed mock later
- Some LOs have no sample question at all
