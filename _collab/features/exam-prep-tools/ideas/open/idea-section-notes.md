# Personal Notes on Learn Sections

## Summary

A small notes box on each Learn section where learners write their own summary or mnemonic, plus a "My notes" list per track. Writing in your own words is a proven memory aid, and the notes are there when revising.

## Why it fits

Learn shows one section per view with "Mark studied & next", so a per-section note fits that rhythm. Section ids (`5.3.3`) are stable keys, and progress already lives in per-track localStorage.

## Scope

- Collapsible note field under each Learn section, autosaved
- "My notes" view per track (on the track page or Summary step), ordered by section
- Notes included in the root backlog's export/import task

## Risks & unknowns

- localStorage size limits are generous but not unlimited
- Notes are lost if browser data is cleared, until export/import exists
