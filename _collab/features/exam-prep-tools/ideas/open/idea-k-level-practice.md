# Practice by K-Level and Question Type

## Summary

Add K-level filters (K1 recall, K2 understand, K3/K4 scenarios) and a points filter (2-point questions) to Practice mode. Learners who keep losing points on scenario questions can drill only those.

## Why it fits

Every question already has `level` and `points`, but QuizPage's practice filter only offers sample set and chapter. On points-weighted tracks (CT-SEC, CTAL-TAE, CT-FT) K3/K4 questions are worth 2–3 points, so they decide the result.

## Scope

- K-level chips beside the chapter chips in Practice
- Optional "multi-point only" toggle
- Counts per filter, like the chapter chips

## Risks & unknowns

- Small pools on some tracks (e.g. CT-UT has 3 K3 questions)
