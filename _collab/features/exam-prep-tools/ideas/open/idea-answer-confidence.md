# Answer Confidence and Lucky-Guess Detection

## Summary

Before submitting a practice answer, learners tap Sure / Unsure / Guess. The review then separates confident mistakes (misconceptions) from lucky guesses (right answer, weak knowledge), which a plain score hides.

## Why it fits

The study-experience idea rates confidence per Learn section; this is per quiz answer and feeds review. Practice mode already reveals each answer after submit, so one extra tap fits the flow.

## Scope

- Three-way confidence tap before Submit in practice
- Review filters: confident-wrong, guessed-right
- Optional in exam simulation, shown on the result page

## Risks & unknowns

- Extra tap may annoy fast reviewers, so make it optional
